## RQ-E16 — conformal threshold for `calibrate.admit_decision` (FC-5)
**Placeholder:** `memory/calibrate.py` thresholds are hardcoded pending this.
**Hypothesis:** a split-conformal admission threshold achieves a target correctness coverage on admitted claims (e.g. ≥0.90) at a **higher admission rate** than the fixed heuristic at equal coverage.
**Baseline:** the current fixed threshold; also a naive "admit if confidence>0.5".
**Fixture:** a frozen set of claims with ground-truth correct/incorrect labels (reuse verified-ledger outcomes + the conflict-gold set when it lands; if <N labels, report N and mark underpowered — do NOT fabricate labels).
**Metric:** empirical coverage (fraction of admitted that are correct), admission rate, calibration error (ECE), abstention rate.
**Gate (go/no-go):** conformal ≥ fixed on admission-rate-at-equal-coverage by a preregistered margin AND coverage CI lower bound ≥ target. Else keep the fixed threshold and say so.
**Seeds:** ≥20 conformal calibration/test resamples.
**Guard:** never tune the threshold on the test split; conformal validity depends on exchangeability — state the assumption and check it.

## RQ-E17 — value-of-information ranking vs baseline (gates `value_queue` auto-dispatch)
**Placeholder:** `analysis/value_queue.py` `voi`; master-res #10 keeps auto-dispatch OFF until this passes.
**Hypothesis:** VoI ranking of next-tests orders them closer to an expert's ranking than a citation-count / graph-mass baseline.
**Baseline:** rank by citation count; rank by raw downstream edge count.
**Fixture:** an expert-ranked (or expert-labeled top-k) set of candidate next-tests over the demo corpus; freeze + hash. If no expert available, STOP at the frozen bundle (same rule as the conflict-gold set) — do NOT self-rank and call it expert.
**Metric:** Spearman rank-corr + precision@k vs expert; secondary: cost-adjusted VoI-per-dollar.
**Gate:** VoI beats both baselines by a preregistered margin with non-overlapping CIs. Only then does Balanced autonomy permit `public_data`-tier narrow auto-dispatch (#10). Else value_queue stays advisory (human clicks run).
**Seeds:** ≥20 bootstrap over the expert-labeled set.

## RQ-E06 — `load_bearing` (dependency load_score) vs expert "what the field rests on"
**Placeholder:** `dependency.py` `load_score`; drives the flagship (I1.3).
**Hypothesis:** computed `load_score` (weighted by downstream **calibrated_p**, not raw edge count — see I1.3 §7 risk) rank-agrees with an expert's load-bearing set.
**Baseline:** raw downstream edge count (unweighted).
**Fixture:** expert-annotated load-bearing claims on the demo corpus; freeze+hash.
**Metric:** rank-overlap / precision@5 vs expert (ties to I1.3 acceptance gate ≥0.8).
**Gate:** calibrated-weighted load_score beats raw-count baseline vs expert by preregistered margin. Else the flagship renders load with the honest caveat that it's edge-count, not validated leverage.
**Seeds:** ≥20 bootstrap.

## RQ-E15 — abstention-scoring magnitudes (LitQA2 oracle; see I1.5)
**Placeholder:** the reward/penalty magnitudes in the abstention-aware score.
**Hypothesis:** the scoring rule rank-orders known-good vs known-bad answer policies correctly (a well-calibrated abstainer > a confident-guesser > a random policy).
**Baseline:** plain accuracy (no abstention credit).
**Fixture:** the frozen LitQA2 subset (I1.5) + a set of synthetic *policies* (always-answer, always-abstain, oracle, random) — synthetic POLICIES are fine (they're strategies, not fabricated gold answers).
**Metric:** does the score's policy ranking match the intended ordering; overconfidence-rate separation.
**Gate:** scoring correctly ranks the policy set AND does not reward "always abstain" as a top policy. Else revise magnitudes before any LitQA2 score is reported as more than diagnostic.
**Seeds:** ≥20 seeded policy/sample draws.
