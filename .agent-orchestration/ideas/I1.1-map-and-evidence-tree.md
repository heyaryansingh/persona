## 1. Problem

Two gaps block "discipline of believing":

1. **Claims are qualifier-blind.** `Claim` identity is `(subject, object, effect_sign)`. A result in *aged male APP/PS1 mice at 12mo* and one in *human post-mortem cortex* collapse to the same claim — this is exactly the microglia/tau and FTL-context failures in the handoff. No population / model-system / dose / timepoint / direction-magnitude fields.
2. **Synthesis has no derivation.** A review sentence is generated *from* quotes and `checker.py` flags unsupported ones *after the fact* with a paid Haiku pass. There is no structural object linking a synthesis statement → the atomic claims it rests on → the inference that combined them. So "why does Persona believe this synthesized statement?" is unanswerable and unauditable.

RQ-E06 fills both: **atomic claims carry qualifiers; every synthesis statement reduces to qualifier-matched premise claims through one typed inference edge.** The Map view renders that reduction so a human sees the argument, not a prose blob.

## 2. Data model (extends, does not fork, the KG)

### 2a. Qualifier block on Claim (new, optional, additive)
```
Claim.qualifiers = {
  population:   str|null   # "human post-mortem cortex" | "APP/PS1 mouse"
  model_system: str|null   # in vivo | in vitro | post-mortem | cohort
  direction:    "+"|"-"|"na"  # already have effect_sign; keep as canonical
  magnitude:    str|null   # "47.6% reduction" | qualitative
  timepoint:    str|null   # "12mo" | "Braak V-VI"
  n:            int|null    # sample size if stated
  qual_source:  span_ref   # EXACT source span the qualifier came from (same discipline as RQ-E01a)
}
```
Claim **identity does not change** (still `subject|object|sign`) — qualifiers are attributes, so convergence is preserved. Two same-identity claims with **incompatible qualifiers** are the *context_divergence* signal (ties directly into the conflict-review labels in `ideas/001`).

### 2b. Derivation layer (new node + edge types)
```
SynthesisStatement { stmt_id, note_id, text, ts }             # one sentence of a review/dossier
InferenceStep      { infer_id, kind ∈ {deduction, generalization,
                     analogy, statistical, aggregation}, rationale }
Edges:
  (SynthesisStatement)-[:VIA]->(InferenceStep)
  (InferenceStep)-[:FROM_PREMISE]->(Claim)        # 1..n premise claims
  (Claim)-[:SUPPORTED_BY]->(Source)               # already exists — the leaf/evidence
```
A statement is **supported** iff: it has ≥1 premise path AND every premise Claim's qualifiers are *compatible* under the InferenceStep.kind rule (e.g. a `generalization` from mouse→human is flagged unless a bridging premise exists; `aggregation` requires premises share population). **Unsupported = no premise path OR qualifier-incompatible premises.** This makes `checker.py`'s post-hoc flag a *structural* property, cheap to compute, no paid call at render time.

### 2c. Map view = three projections over the same graph
| Projection | Nodes | Edges | Answers |
|---|---|---|---|
| **Argument** | SynthesisStatement, InferenceStep, Claim | VIA, FROM_PREMISE, CONTRADICTS | "why is this believed / where is it contested?" |
| **Evidence** | Claim, Source | SUPPORTED_BY (+ exact span, independent-lab count) | "what does it actually rest on?" |
| **Trajectory** | Claim | valid_from ordering, confidence over time | "how did understanding develop?" (reuse existing idea-over-time) |

Reuse `kg.graph_*` exporters; add derivation nodes to the export payload (S6 owns `graph.js`/`map.js`). One graph, three filters — not three data pipelines.

## 3. Interactions (for S3, non-binding UX intent)
- Click a synthesis sentence → Argument projection expands its derivation tree to the leaf sources with exact spans.
- Unsupported statements render in the "needs-human" accent (per design principles); qualifier-incompatible premises show the mismatched fields inline.
- Contradiction/candidate-conflict nodes deep-link into the conflict-review dossier (`ideas/001`).
- Motion only on real state change (a premise arriving, a statement flipping supported↔unsupported).

## 4. Novelty vs named competitors (defend to a PhD)
- **scite:** classifies *citations* (supporting/contrasting/mentioning) one at a time. No qualifier typing, no premise→conclusion derivation, no structural unsupported-synthesis gate. Persona reduces a *synthesized claim* to qualifier-matched premises — a level scite doesn't model.
- **PaperQA2:** strong RAG answer+citation but ephemeral per-query; no persistent claim graph, no qualifier layer, no cross-paper derivation audit. Persona's derivation persists and is re-auditable.
- **Open Targets:** curated target–disease evidence graph, fixed human-curated schema. Persona builds the derivation layer *live over free-text* with typed inference and context divergence.
- **MedKGent / KARMA / AutoBioKG:** LLM triple-extraction KGs. They stop at triples; none carries a qualifier-compatible derivation graph nor a live gate that blocks unsupported synthesis. **That derivation-audit layer is Persona's contribution.**

## 5. Falsifiable metrics + gates (experiment-first, AGENTS.md §2)
Run an experiment BEFORE shipping the layer — `experiments/exp_rq_e06_evidence_tree.py`, ≥20 seeds (bootstrap over a held-out synthesis set).

- **M1 — unsupported-synthesis rate.** Oracle = `checker.py` support_rate on a held-out set of synthesis statements (or human labels where available). Baseline = current free-generation synthesizer. **Gate: derivation-constrained synthesis reduces unsupported statements ≥50%** (CONTINUATION §7.4).
- **M2 — qualifier recall.** Gold = human-annotated qualifier set on a stratified claim sample; recall = fraction captured on the atomic claim. **Gate: ≥10-point recall gain** vs current no-qualifier extraction.
- **Guard against gaming:** report qualifier *precision* alongside recall (don't reward hallucinated qualifiers — same trap as the rejected lexical-polarity gate in RQ-E01a); every qualifier must cite an exact source span or it's rejected.
- **No-go:** if derivation-constrained synthesis cuts unsupported <50% OR tanks statement coverage (statements dropped because no premise path) below an acceptable recall, keep post-hoc `checker.py` and ship qualifiers only.

## 7. Open risks
- Qualifier taxonomy could balloon — freeze the 6 fields above; add only on measured need.
- Compatibility rules per inference `kind` are themselves a modeling choice → each rule needs a test case before it gates anything.
- Derivation extraction may be a second paid pass — measure token cost vs the current single Haiku `checker` call; if net-costlier with no unsupported-rate win, reject.
