# I1.7 — A8 "Provenance & Process" section schema (ready spec for imp4)

**Author:** S1 (idea) · **For:** imp4 (deliverables). **Spec only — imp4 implements in `persona/deliverables/*`.**
**Assigned by:** S0 dispatch task #3 (2026-07-13) + board line 27 ("idea+coord: A8 schema, grounded/reproducible"). **Binds:** S0's A8 draft (6 sections), the "biggest user-requested item." Ties to I1.4 (capsule hashes).
**Grounded in real code** (`persona/sessions.py`): event = `{event_id, parent_event_id, at, kind, payload}`; artifact event kind `artifact_stored`, payload has `sha256/bytes/media_type/path`; verdict kind `verifier_verdict`, payload `{verdict, reason}`; session meta carries `events_sha256` (integrity) + `verification`. Rejects: per-source `claims_rejected.jsonl` (`reading/reader.py`, `batch.py`) + KG `provenance='REJECTED_EXTRACTION'` + `correction_reason` (`memory/kg.py`).

## 0. The one hard rule
**Every rendered number cites a real logged source (event_id / artifact sha256 / jsonl line) — NOT model prose.** The section is a *projection of `events.jsonl` + claims files*, regenerable and byte-identical on re-render. A datum with no backing event renders as "**not recorded**", never `0` and never an estimate. This is the RQ-E01a discipline applied to the report itself.

## 1. imp4 MUST scout before implementing (S0 blocked-by)
Do NOT hardcode the pipeline stages. First **enumerate the distinct `kind` values actually present** in real `events.jsonl` (e.g. `python -c "import json,collections; ..."` over `personas/*/runs/*/events.jsonl`), and map each A8 row to the kinds that truly exist. If a section's source kind isn't present in a given session, that section renders "not recorded for this run" — the report never claims a stage ran that left no event.

## 2. Section schema (each row = {what, real source, grounding key})
| # | Section | Content | Real source | Grounding key per number |
|---|---|---|---|---|
| 1 | **Reading funnel** | N fetched → relevance-passed → read → claims extracted → **admitted / rejected** (+ reject-reason breakdown) | count events by `kind`; `claims.jsonl` vs `claims_rejected.jsonl`; membrane/gate log | each count links the `event_id` range or the jsonl line count it was derived from |
| 2 | **Agent contributions** | the pipeline that actually ran, each stage's items-processed | group events by `kind`, count per kind (stages = the enumerated real kinds, §1) | per-stage count → the `kind` it counts |
| 3 | **Sources** | admitted (DOIs) vs quarantined (+ reason) | `claims.jsonl` (admitted) / `claims_rejected.jsonl` + KG `REJECTED_EXTRACTION.correction_reason` | each DOI → its claim_id; each quarantine → its reason string |
| 4 | **Computations** | each sandbox run: what it checked + input/script/image **hashes** + pass/fail | `artifact_stored` events (`payload.sha256/media_type`) + sandbox capsule (I1.4 `{input_sha256, script_sha256, sandbox_image_digest}`) | each row → artifact `sha256` + session_id |
| 5 | **Robustness verdict** | auditor band + likelihood + interval + failing checks | `verifier_verdict` event + `audit.py` output + `meta.verification` | verdict → the `verifier_verdict` event_id |
| 6 | **Traceability** | each headline claim → evidence IDs → sources | claim → `SUPPORTED_BY` sources (kg) → DOIs | claim_id → evidence_id → source DOI chain |

## 3. Reproducibility contract
- The section is rendered from `events.jsonl` whose integrity is already `events_sha256`-verified (`sessions.verify_session`). A8 rendering MUST call that verify first; if the event log fails integrity, A8 renders "**provenance unavailable — event log failed integrity check**", not partial numbers.
- Given the same session, re-rendering A8 is byte-identical (no wall-clock, no model call in the render path).
- No model prose in the numeric path. A model may write connective sentences ONLY around numbers that already carry a grounding key — and the pre-ship lint (D) rejects an A8 with any ungrounded number.

## 4. Acceptance gate
- **Runnable check** (`tests/test_paper_a8_provenance.py`, offline, $0): render A8 from a real completed session (e.g. the E12b or microglia session), assert (a) every number in the rendered section maps to a real event_id/sha256/jsonl-line (no orphans), (b) re-render is byte-identical, (c) a tampered `events.jsonl` (fails `events_sha256`) makes A8 render the integrity-failure state, not numbers, (d) a session missing a stage renders "not recorded", not `0`.
- **Lint hook (D):** `paper_lint` already blocks ship on A8 — extend it to reject an A8 section containing a number with no grounding key.

## 5. Risks
- **Invented fields:** the top risk S0 named — hence §1 scout-first. If imp4 finds the real logs lack a datum (e.g. no membrane reject log for old sessions), the section degrades honestly, never backfills with a guess.
- **Model creep:** the moment a headline number comes from model prose instead of an event, A8 stops being provenance and becomes marketing — the lint + orphan-check test are the guard.
- **Cross-session bleed:** A8 is per-session; assert every event/artifact belongs to the rendered session_id (no leak from another run — the multipersona-isolation discipline).
