The problem

Our research tools are amnesiac

Science publishes millions of papers a year, and there is a reproducibility crisis underneath them. But a chatbot answers and forgets, and a search tool retrieves without ever holding a belief, noticing a contradiction, re-checking itself, or acting. An on-off agent with no memory and no self cannot be a researcher. The bottleneck is not generating text — it is a trustworthy memory that reads at scale, believes with discipline, and compounds.

What it is

A small durable self, a large disposable swarm

Persona separates a persistent self — interests, a provenance-typed belief-state, memory, taste — from an ephemeral swarm of bounded agents that read at scale and are then discarded. Scale of reading, discipline of believing. Every belief carries a provenance type (READ, INFERRED, HUMAN_CONFIRMED, TESTED), so an inferred claim never wears the authority of a proven one.

Capabilities

What a researcher can actually use

Grounded, cited reports no hallucinations

Select a region of the graph or upload a paper and get a report where every claim resolves to a real author, journal, and DOI, exportable to PDF.

Robustness auditor forensics in code

statcheck, GRIM, GRIMMER, power and p-curve run in code, never a model, then a replication likelihood calibrated on real replication outcomes. Adversarial refuters stress-test the soft calls.

Verified reasoning sympy & Lean 4

Derivations are machine-checked in sympy or formally proven in Lean 4. Nothing is asserted that was not verified, and results are re-tested over time.

Agent teams that act the acting loop

A director assigns non-overlapping questions to teams that gather, synthesize, reason, prove, and write in parallel — then escalate to a human exactly when judgment is needed.

Living knowledge graph over publication time

Every claim becomes a node with its year and DOI; contradictions surface as the field moves, so you see what it actually rests on.

A transparent workbench not a black box

Its whole mind is on disk as folders. Watch agents work live, open the code editor, and run their Python in a sandbox yourself.

What makes it different

Others retrieve and score. Persona remembers and acts.

A chatbot / search tool

  • Answers, then forgets the session
  • Citations may be fabricated
  • No beliefs, no contradictions, no self-correction
  • Never runs an experiment or acts

Persona

  • Holds a durable, provenance-typed belief-state
  • Every claim traces to a real paper, year, and DOI
  • Flags contradictions and re-audits its own past conclusions
  • Runs code, proves math, and hands you what needs a human
Under the hood

Built with Claude Code. Claude reasons, code verifies.

A single mind runs on a heterogeneous fleet of Claude models, routed by task. The governing rule is that Claude reads and reasons while the arithmetic is run in code and checked — the difference between a plausible number and a trustworthy one.

Opus  reflects & judges Sonnet  reads, reasons & writes Haiku  scouts

We tested our own design

Under sustained, correlated literature poisoning, human-anchored memory kept 100% of verified beliefs; naive continuous updating kept only 71%. Under benign noise, protection buys nothing — a reversal we kept and diagnosed.

Calibrated, not vibes

Replication likelihoods are fitted on real labeled outcomes (Open Science Collaboration 2015, Gordon 2021), beating a flat base rate on a proper scoring rule — so 70% means 70%.

Run and experiment yourself

Seed a mind, then leave it running

The whole system is open source and runs locally with your own Anthropic key. Give a persona a few interests and watch what it becomes.

  1. Get the code

    git clone https://github.com/heyaryansingh/persona
cd persona
pip install -r requirements.txt

  2. Add your API key

    Create a .env file in the repo root. Only ANTHROPIC_API_KEY is required; it stays on your machine.

    ANTHROPIC_API_KEY=sk-ant-...        # required (console.anthropic.com)
ARISTOTLE_API_KEY=...               # optional - Lean 4 formal proofs
CONTACT_EMAIL=you@example.com       # optional - polite literature-API user-agent

  3. Optional: the full stack (Docker)

    docker run -d -p 6379:6379 falkordb/falkordb                   # the belief graph
docker build -t persona-sandbox -f docker/sandbox.Dockerfile .   # runs agent code + compiles PDFs

  4. Run it

    python -m persona --port 8137

    Open http://127.0.0.1:8137, create a persona, and seed it with a few interests. Tests run offline with python -m pytest -q.
