## 1. What this program is

Persona is already deep: a multi-persona always-on daemon, an investigation-driven swarm, a provenance-typed FalkorDB belief graph, a membrane, an evidence-first session substrate, a real code-run robustness auditor, and ~75 API routes. The highest-leverage moves are **not** new subsystems — they are (a) wiring primitives that exist-but-aren't-connected into closed loops, and (b) upgrading the swarm from a *linear pipeline* into a *heterogeneous, verifying team* — both strongly backed by 2024–2026 research. This program packages that into four parallelizable lanes.

### Decisions locked with the user (2026-07-12)
| Decision | Choice |
|---|---|
| First-wave themes | **All four** lanes green-lit |
| Autonomy posture | **Balanced** — auto-open/re-investigate + narrow reanalysis into TESTED-provisional; **any anchor or high-stakes update stays human-gated** |
| Flagship UI | **"Field-rests-on-this + value queue"** (dependency/load-bearing map + VoI÷cost experiment queue) |
| Self-benchmarking | **Now** — LitQA2/BixBench oracles + cost-adjusted scorecard + RO-Crate export |

### The four lanes
1. **Heterogeneous agent teams** (`PRD-01`) — branching/DAG investigations, a dedicated tool-grounded verifier agent, two-reader cross-check, gated debate, span-weighted consensus with protected dissent, surprise-ranked tension queue, and the loop-closing `open_from_conflict`. *Serves "breadth of agent teamwork."*
2. **Dual-signal calibrated membrane & belief core** (`PRD-02`) — admit only when NLI-span **and** KG-support agree; conformal abstention → human handoff; recomposition/feasibility gate; knowledge-conflict typing (RQ-E02 substrate); temporal confidence + validity windows; wire the dead signals (`drift`, `poisoning_signals`) into action. *The epistemic core.*
3. **Intellectual engine, forensics & data acting-loop** (`PRD-03`) — dependency/load-bearing graph, value-of-information queue, citation-vs-support divergence, trajectory + dead-science meter, Retraction-Watch contamination audit, a deeper auditor, and end-to-end GEO dataset resolution. *The differentiator.*
4. **Legibility, flagship UI, API & self-benchmarking** (`PRD-04`) — the flagship screen, a robustness "trust" tab, a first-class handoff inbox, an epistemic-status/RQ-gate dashboard, per-agent cost-vs-yield, and the benchmark harness. *The product thesis is legibility.*

## 2. Non-negotiable epistemic discipline (applies to every lane)

Restated from `CLAUDE.md` + the HANDOFF frozen contracts (which remain authoritative):

- **No fabricated confidence.** Any surfaced number is validated on held-out data, never a model self-report.
- **Exact-span grounding.** No belief typed `READ`/`TESTED` without a located entailing source span (offsets stored). **Abstain rather than fabricate.**
- **Human anchors high-stakes.** The swarm READS; it never writes the self directly; nothing auto-anchors the KG. `candidate_conflict ≠ verified contradiction` until RQ-E02 passes its gate.
- **Provenance typing everywhere:** `READ / INFERRED / HUMAN_CONFIRMED / TESTED`.
- **Forensics run in CODE, never a model**, and each check declares an **applicability gate** and emits a `skipped/not-applicable` state distinct from `passed` (out-of-domain false positives are the correctness boundary).
- **Research-and-verify:** any load-bearing/uncertain choice = hypothesis + metric + go/no-go gate, tested in a seeded (≥20-trial) `/experiments` sandbox with results in `/results`, **before** implementation, cited in a code comment. Reversals are logged. Do **not** gold-plate trivial choices.
