## The differentiators (what nobody else ships)
1. **Executable molecular/genetic verification → TESTED without a human:** run Mendelian-randomization, DepMap knockouts, gnomAD/GTEx/OT-Genetics gates, LEGEND calibrated-RWE, and real meta-analyses in code — self-guarded by positive/negative control injection.
2. **The acting loop, closed:** contradiction → dependency/value-of-information → located public dataset → sandboxed reanalysis → replayable artifact → append-only belief update **or** human handoff.
3. **A persistent self + a second-researcher lab**, calibrated abstention as the human-handoff trigger, and the whole machinery legible (mind-at-work, not a dashboard).
